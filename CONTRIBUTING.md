# Contributing / Участие

Thanks for your interest! / Спасибо за интерес к проекту!

- **Bugs and ideas:** open an [Issue](https://github.com/luviel19/Music_Island/issues). For Spotify problems attach the diagnostics from the tray menu (it has no cookies or tokens). Never post tokens, cookies or VPN links.
- **Pull requests:** keep them focused. Run `npm test` and `node scripts/check-site.js` before sending. If you change `scripts/build-site.js`, run `node scripts/build-site.js` and commit the regenerated `docs/`.
- **Honesty rule:** the island shows only functions that really work (`caps` in a provider). Do not add imitated buttons or claims in the docs that the code does not back up.
- **Not accepted:** private or unofficial Spotify endpoints, cookie/token extraction from other browsers, ad blocking, DRM/TLS bypass.
- **Setup:** Windows 10/11, Node.js 20+, `npm install`, `npm run build:spotify`, `npm start`.

Commits: short imperative messages in English or Russian. / Сообщения коммитов: короткие, по делу, на английском или русском.
