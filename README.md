# Music Island

**Dynamic Island для рабочего стола Windows.**<br>
Маленький остров с вашей музыкой: висит на экране, раскрывается при наведении, играет цветом обложки.

## ✨ Возможности

| | |
|---|---|
| 🎛 **Много площадок в одном окне** | Яндекс Музыка, SoundCloud, YouTube и системный плеер. Переключение через выпадающий список прямо на острове |
| 🔎 **Поиск по всем площадкам** | Введите название песни: остров ищет сразу в Яндекс Музыке, SoundCloud и YouTube, склеивает одну песню в одну строку и показывает значки площадок, где она нашлась. Клик по значку включает песню именно там. Плашки площадок над результатами работают как фильтр |
| 🔔 **Уведомление об обновлении** | Когда на GitHub выходит новый релиз, остров показывает уведомление с кнопкой «Скачать» |
| 🌊 **Волновой прогресс-бар** | Палочки, повторяющие форму песни. Клик по волне перематывает |
| 🟪 **Светодиодный эквалайзер** | На фоне острова играет сетка из квадратиков в цвет обложки трека |
| 🎚 **Компактный эквалайзер** | Живой градиентный индикатор, когда остров свёрнут |
| ❤️ **Лайки, очередь, карточка трека** | Листайте треки, открывайте подробности, ставьте лайк |
| 🔊 **Громкость, перемешивание** | Всё под рукой в раскрытом острове |
| 🖱 **Свободное перемещение** | Перетащите остров в любое место экрана, позицию можно заблокировать |
| 📌 **Поверх всех окон** | Включается и выключается одним кликом |
| ⌨️ **Медиа-клавиши и трей** | Глобальные горячие клавиши, меню в трее, автозапуск |
| 🔐 **Безопасное хранение входа** | Токены шифруются средствами системы (Electron `safeStorage`) |

## 🎵 Площадки

| Площадка | Что есть | Вход |
|---|---|---|
| <img src="https://img.shields.io/badge/-Яндекс%20Музыка-FFDB4D?style=flat-square&logoColor=black" /> | «Моя волна», «Избранное», лайки | OAuth-токен |
| <img src="https://img.shields.io/badge/-SoundCloud-FF5500?style=flat-square&logo=soundcloud&logoColor=white" /> | Тренды, ваши лайки, трек по ссылке | Необязателен, нужен для лайков |
| <img src="https://img.shields.io/badge/-YouTube-FF0000?style=flat-square&logo=youtube&logoColor=white" /> | Поиск, микс по ссылке на видео | Не нужен |
| <img src="https://img.shields.io/badge/-Системный%20плеер-7B61FF?style=flat-square&logoColor=white" /> | Всё, что играет в Windows: Spotify в браузере или приложении, VK, Apple Music и другое | Не нужен |

> **Про Spotify.** Официальный Web API требует Premium у владельца приложения, поэтому напрямую он не подключён.
> Зато Spotify (как и любой плеер Windows) работает через пункт **«Spotify и другие»**: остров читает и управляет им через системные медиа-элементы Windows (SMTC). Отдельный вход не нужен.

## 📥 Установка

1. Скачайте `Music-Island-Setup-*.exe` из раздела **[Releases](../../releases)**.
2. Запустите установщик, выберите папку и дождитесь окончания.
3. Остров появится на экране, а иконка в трее даст доступ к настройкам.

> [!NOTE]
> Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать окно «Windows защитила ваш компьютер».
> Нажмите **«Подробнее» → «Выполнить в любом случае»**.

<br>

## 🛠 Запуск из исходников

```bash
git clone https://github.com/luviel19/Music_Island.git
cd Music_Island
npm install
npm start
```

Сборка установщика:

```bash
npm run dist
```

Готовый `Music-Island-Setup-*.exe` появится в папке `dist/`.

<br>

## 🔑 Вход

- **Яндекс Музыка.** Остров сам подскажет, как получить токен, и покажет кнопку вставки. Токен хранится только на вашем ПК, в зашифрованном виде.
- **SoundCloud.** Музыку можно слушать без входа. Для лайков вставьте значение cookie `oauth_token`.
- **YouTube и системный плеер.** Вход не нужен.

<br>

## 🧩 Архитектура

Каждая площадка подключается как **провайдер** из двух частей:

```
providers/<id>.js        основной процесс: сеть, токены, доступ к системе
src/providers/<id>.js    интерфейс: воспроизведение, очередь, управление
```

Общий контракт описан в `src/providers/registry.js`. Чтобы площадка участвовала в поиске, добавьте ей метод `search(host, запрос)`, а для запуска найденного трека метод `open(host, трек, список)`. Чтобы добавить новую площадку, создайте пару файлов, подключите её в `providers/index.js` и `src/index.html`. Всё остальное (выпадающий список, трей, эквалайзеры, лайки, очередь) подхватится само.

```
.
├── main.js               окно, трей, настройки, перетаскивание
├── updater.js            проверка новых релизов на GitHub
├── preload.js            мост между окном и основным процессом
├── providers/            провайдеры основного процесса (+ мост SMTC на PowerShell)
├── src/                  интерфейс острова
│   ├── app.js            ядро: состояния, эквалайзеры, волна, меню
│   ├── search.js         поиск по площадкам и склейка результатов
│   └── providers/        провайдеры интерфейса
└── assets/               иконки и скриншоты
```

## ⚠️ Ограничения

- Только Windows 10 и 11.
- Яндекс Музыка и SoundCloud используют неофициальные API: они могут измениться без предупреждения.
- Звук и VK не поддерживаются: у первого защита от ботов, у второго закрыт API.
