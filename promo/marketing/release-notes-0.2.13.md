## Music Island 0.2.13 — караоке, альбомы, обложки / Karaoke, albums, covers

### Что нового

- **Караоке.** Кнопка с микрофоном рядом с сердечком открывает большое окно со словами. Видны 4 строки: прошлая, текущая и две следующие, текущая подсвечивается в такт песне. Колесо мыши листает слова, клик по строке перематывает на неё. Сверху остаётся свёрнутый остров, при наведении он раскрывается. Тексты берутся из открытой базы LRCLIB: туда уходят только название, исполнитель, альбом и длительность трека.
- **Поиск альбомов.** В поиске появилось переключение «Песни / Альбомы». В Яндекс Музыке найденный альбом играет целиком, для Spotify открывается официальная страница альбомов в панели.
- **Остров у края экрана.** Углы, которые касаются края, больше не скругляются: остров сливается с краем. В центре экрана всё как раньше.
- **«Вернуть в центр экрана»** центрирует на том мониторе, где остров сейчас, а при нескольких мониторах можно выбрать нужный.
- **Системный плеер.** Подтягивается обложка у «Медиаплеера» Windows и у плееров, которые отдают её с задержкой (Spotify). Вместо технического имени показывается название приложения.
- **Мелочи.** Визуализатор растянут на всю ширину острова, кнопки управления стоят строго по центру.

### What's new

- **Karaoke.** A microphone button next to the heart opens a large lyrics window. Four lines are shown: previous, current and the next two, the current one is highlighted in time with the song. Mouse wheel scrolls the lyrics, a click on a line seeks to it. The collapsed island stays on top and expands on hover. Lyrics come from the open LRCLIB database: only the title, artist, album and duration of the track are sent.
- **Album search.** Search now switches between Songs and Albums. In Yandex Music a found album plays in full, for Spotify the official albums page opens in the panel.
- **Island at a screen edge.** Corners that touch a screen edge are no longer rounded, so the island merges with the edge. In the middle of the screen nothing changes.
- **"Return to screen center"** centers on the monitor where the island currently is, and with several monitors you can pick one.
- **System player.** Covers now load for Windows Media Player and for players that provide them late (Spotify). The app name is shown instead of the technical identifier.
- **Small things.** The visualizer spans the full island width and the transport buttons are exactly centered.
