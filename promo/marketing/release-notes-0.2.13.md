## Music Island 0.2.13 — караоке, альбомы, обложки / Karaoke, albums, covers

### Что нового

- **Караоке.** Кнопка с микрофоном рядом с сердечком открывает большое окно со словами. Сверху остаётся свёрнутый остров (при наведении он раскрывается). Видны 4 строки: прошлая, текущая и две следующие; текущая подсвечивается в такт песне. Колесо мыши листает слова, клик по строке перематывает на неё. Тексты берутся из открытой базы LRCLIB: туда уходят только название, исполнитель, альбом и длительность трека.
- **Поиск альбомов.** В окне поиска появилось переключение «Песни / Альбомы». Яндекс Музыка: найденный альбом запускается целиком. Spotify: открывается официальная страница альбомов в панели.
- **Остров у края экрана.** Углы, которые касаются края экрана, не скругляются: остров сливается с краем. В центре экрана всё как раньше.
- **«Вернуть в центр экрана»** теперь центрирует на том мониторе, где остров висит сейчас, а при нескольких мониторах есть выбор монитора.
- **Системный плеер.** Обложка теперь подтягивается у «Медиаплеера» Windows и у плееров, которые отдают её с задержкой (Spotify). Вместо технического имени показывается название приложения.
- **Визуализатор** растянут на всю ширину острова, кнопки управления стоят строго по центру.
- **SoundCloud:** исправлены лайки (0.2.12).

### What's new

- **Karaoke.** A microphone button next to the heart opens a large window with the lyrics. The collapsed island stays on top (it expands on hover). Four lines are shown: previous, current and the next two; the current one is highlighted in time with the song. Mouse wheel scrolls the lyrics, a click on a line seeks to it. Lyrics come from the open LRCLIB database: only title, artist, album and duration of the track are sent.
- **Album search.** The search window now switches between Songs and Albums. Yandex Music: a found album plays in full. Spotify: the official albums page opens in the panel.
- **Island at a screen edge.** Corners that touch a screen edge are no longer rounded, so the island merges with the edge. In the middle of the screen nothing changes.
- **"Return to screen center"** now centers on the monitor where the island currently is, and with several monitors you can pick one.
- **System player.** Covers now load for Windows Media Player and for players that provide them late (Spotify). The app name is shown instead of the technical identifier.
- **Visualizer** now spans the full island width and the transport buttons are exactly centered.
- **SoundCloud:** likes fixed (0.2.12).
