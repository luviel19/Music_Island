- **Short description (up to 150 chars):** Free open-source Dynamic Island music player for Windows with Spotify, Yandex Music, YouTube and SoundCloud.
- **Description:** Music Island is a floating Dynamic Island-style widget for the Windows desktop. It shows the current track, a waveform progress bar and controls, expands on hover and adapts to the cover art. It controls Spotify (official web player embedded in WebView2, Free and Premium), Yandex Music, YouTube, SoundCloud and any system media player, with search across services, queue, a 10-band equalizer for Yandex Music and SoundCloud, media keys and a tray menu.
