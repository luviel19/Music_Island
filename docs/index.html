A free Dynamic Island music player for Windows

Music Island is a small floating island on your desktop. It shows what is playing, expands on hover and controls Spotify, Yandex Music, YouTube and SoundCloud. Open source, MIT license, Windows 10/11.

What you get

Everything here is implemented in the current release.

Floating island

Always on top of your windows, expands on hover, never leaves the screen and can sit in the very corner. Click-through where it is transparent.

Several services, one island

Spotify, Yandex Music, SoundCloud, YouTube and any system media player. Switch from the island or the tray.

Search across services

One query searches Yandex Music, SoundCloud and YouTube. The same song is merged into one row with service icons.

Waveform progress

Bars that follow the shape of the song. Click to seek. Colours adapt to the cover art.

10-band equalizer

For Yandex Music and SoundCloud: manual bands, presets and a colourful grid in the island background.

Queue, likes, media keys

Browse the next tracks, like songs (Yandex Music, SoundCloud), use global media keys and the tray menu. Autostart with Windows.

Spotify and Yandex Music

The two main services, and how they connect.

Spotify: the official web player

The island embeds the official open.spotify.com web player in Microsoft Edge WebView2. You sign in on the real Spotify page (Free or Premium), the password stays with Spotify. No Web API, no Client ID, no developer keys, no cookie extraction and no ad blocking. Playback is controlled through Windows media controls, the queue is read from the page, volume is the Windows audio session of the player. Ads in the Free plan play as in a normal browser.

Yandex Music: My Wave and Favorites

My Wave with mood and activity tuning, Favorites, likes, queue, equalizer and search. Sign-in uses an OAuth token that is stored encrypted on your PC. The Yandex API used here is unofficial and may change.

Spotify in the island has no like, shuffle or equalizer: the embedded web player does not expose them, so the island does not fake them.

Questions and answers

Is Music Island free?

Yes. It is free and open source under the MIT license. The app has no ads and no paid features.

Do I need Spotify Premium?

No. The island embeds the official Spotify web player, so Free and Premium accounts both work. Free-plan ads play as in a browser; the island does not block them.

Does it work on Windows 10 and Windows 11?

Yes, both 64-bit versions. It needs the Microsoft Edge WebView2 Runtime for Spotify, which is part of current Windows installations.

Why is there no like or equalizer for Spotify?

Audio plays inside the embedded Spotify page, which does not expose like or shuffle state. The island only shows functions it can perform honestly.

Is it safe? The installer is not signed.

The source code is open, the app has no keys of its own, and sign-in happens on the official service pages. The installer is not code-signed, so SmartScreen may warn. Download only from the official releases and verify the SHA-256 hash.

SoundCloud or YouTube do not open

If a service is blocked in your country, enable VPN or proxy in the tray menu. It is used only for SoundCloud and YouTube.

Is it affiliated with Spotify, Yandex, YouTube or SoundCloud?

No. It is an independent project. All trademarks belong to their owners.
